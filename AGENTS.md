# Public portfolio

The site uses Astro. Read `docs/style-guide.md` before changing the interface and
`README.md` for the route map and browser checks. The systems pages consume
sanitized, read-only telemetry.

Use `bash .codex/setup.sh` to install from the lockfile and
`bash .codex/validate.sh` to run the numerical tests, Astro checks, and static
build. See `.codex/README.md` for the cloud setup.

Cloud work on this repository covers the public portfolio. Keep proprietary
implementations, unpublished research, private infrastructure details,
production logs, and credentials on the owner's local or self-hosted systems.
